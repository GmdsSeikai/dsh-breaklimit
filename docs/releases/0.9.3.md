# dsh-breaklimit 0.9.3 内测版

这是 dsh-breaklimit 的首个内测发布版本。它为 DeepSeek Harness 源码版提供中英文 Web 设置页，可以选择宿主补丁、编辑提示词，以及保存和切换规则。0.9 系列用于内测，正式版计划为 1.0.0。

## 补丁：按需选择，应用前检查

在设置的「破限 → 补丁」中逐条选择要应用的改动。应用前会检查宿主版本和文件内容；发现不匹配时会停止，避免把补丁写到不兼容的源码上。需要恢复原状时，可以回退已应用的补丁。

应用补丁会修改宿主源码，需要重启宿主才能完整生效。使用同一份源码的其他 profile 也会读到这些改动，独立 profile 只隔离配置。

## 提示词：切换模式，也可以自己编辑

提供「推荐」和「完全解放」两种提示词模式，也可以编辑自己的正文。聊天区的「破限」入口可以快速切换模式和管理目标词表，完整设置放在「提示词与规则」页。

提示词模式不改变宿主的执行权限；实际权限仍需查看宿主的沙箱和审批设置。

## 规则：保存多份，选择一份激活

可以给不同用途保存各自的规则，需要时再激活到 `AGENTS.md` 或 `CLAUDE.md`。取消激活时恢复原内容；目标文件被其他程序改动后，会保留改动并提示处理。

编辑后尚未保存的规则，在切换条目、取消或关闭页面时会提醒确认，减少误操作丢失正文的情况。

## 修复

- 多次恢复损坏的规则清单时，每次都会保存独立备份，修复了同一秒内恢复可能覆盖旧备份的问题。备份失败时不会重置原清单。
- 修复补丁回退写入未完成却可能显示成功的问题。现在会核对恢复结果；失败时保留恢复记录，便于处理后重试。

## 安装与升级

适用于已能运行的 DeepSeek Harness **源码版 0.2.1-rc.2**，固定宿主提交为 `687f282e8625c6b8d11ff58211a90524be2e4317`。需要 Git、pnpm 和兼容的 Node.js，推荐 Node 24。

**第一次安装？** 下载附件 `dsh-breaklimit-0.9.3.zip`，解压到固定目录，再按 [README 安装指南](https://github.com/rumoii/dsh-breaklimit/blob/v0.9.3/README.md#快速安装windows-powershell) 准备 Web profile、安装插件、运行检查并应用补丁。

已经在用 0.9.2 的用户，保存本地修改后更新插件目录，再重启宿主即可。保留原有的 `DSH_HOME`、规则和恢复快照；这个版本没有改变补丁内容与规则存储格式。更早版本的升级差异，以及回退和卸载步骤，见 [安装说明](https://github.com/rumoii/dsh-breaklimit/blob/v0.9.3/docs/install.md)。

## 使用范围

仅用于受信任的本机 Web 环境。插件管理接口尚未接入宿主登录认证，请勿将端口暴露给不受信任的网络。操作规则时，也请避免其他程序同时改写规则文件。

本次已完成 Windows 源码版安装与浏览器验收。桌面版、其他宿主版本、Ubuntu 实际安装、完整模型与沙箱场景尚未验收。
