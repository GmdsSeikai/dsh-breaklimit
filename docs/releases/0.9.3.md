# dsh-breaklimit v0.9.3 内测版

这一版补强恢复数据保护，并建立从源码检查、打包到草稿附件下载核验的发布流程。0.9 系列仍在内测，正式版计划为 1.0.0。

## 恢复数据保护

- 同一秒多次恢复损坏的规则清单时，每次保留独立备份，不覆盖上一次原件。备份按字节核对，不能仅凭大小一致就重置清单。
- 备份失败不重置；重置失败保留原清单和备份。备份仍位于 `$DSH_HOME/dsh-breaklimit-backup/`，同秒重名时目录带随机后缀。
- 补丁回退和失败补偿读回核验恢复内容；内容不符时保留恢复记录，报告失败并允许处理后重试。

v0.9.2 标签保持原样，未创建该版本的 Release；请使用包含上述修复的 v0.9.3。

## 安装与升级

适用于 DeepSeek Harness **源码版** `0.2.1-rc.2`，固定提交 `687f282e8625c6b8d11ff58211a90524be2e4317`。Node 要求 `^22.19.0 || >=24.0.0`，推荐 Node 24；需要 Git 和 pnpm。

首次安装可以下载源码 ZIP，或运行：

```powershell
git clone --branch v0.9.3 --depth 1 https://github.com/rumoii/dsh-breaklimit.git
```

之后按包内 README 创建独立 Web profile、安装插件、执行 `--doctor`、预检与应用，再启动宿主。SHA-256 见 `SHA256SUMS.txt`，完整源提交及宿主信息见 `release-metadata.json`。

从 0.9.2 升级不改变补丁声明和规则持久格式；更新插件目录后重启宿主。保留现有 `DSH_HOME`、规则与恢复快照。更早版本的提示词与规则格式差异见 CHANGELOG。

回退宿主补丁时，在插件目录执行 `node src/cli.js --host-root '<宿主根>' --revert`，成功后重启。卸载插件不会自动回退源码或清除用户数据；完整步骤见 `docs/install.md`。

## 验证与限制

源码检查、实际下载附件检查、真实安装与浏览器结果分别记录；草稿准备成功不等于已验收。每次验证的源 SHA 和附件哈希以对应报告为准。

仅支持受信任的本机 Web 环境。HTTP 管理接口的同源限制不等于独立认证，目前未接入宿主登录认证，不应将端口暴露给不受信任网络。规则存储对不持锁外部写者的 revision CAS 窗口仍然存在。

桌面发行版、其他宿主版本、Ubuntu 实际安装、完整模型与沙箱场景不作为已通过事实。项目采用 MIT 许可。
