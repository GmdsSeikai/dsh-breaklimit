# 发布检查清单

本清单供维护者使用，不会触发提交、推送或发布。

## 代码与产物

- [ ] 确认分支、HEAD、工作区及将进入发布的文件范围。
- [ ] 逐项检查代码、提示词、注释、素材来源及适用许可；名称扫描和相似度结果仅为辅助证据。
- [ ] 无凭据、个人路径、用户数据和任务日志；检查当前文件与拟发布的历史范围。
- [ ] `npm run check`、`git diff --check` 通过。
- [ ] GitHub Actions 的 Windows、Ubuntu × Node 22.19、24 检查通过。
- [ ] 固定宿主的 `reconcile` 与 `check:host` 通过。
- [ ] `npm pack --dry-run --ignore-scripts` 中的入口、模块、默认提示词、哈希、许可证和文档齐全。

## 安装与界面

- [ ] 独立源码副本和新数据目录按 README 完整执行，记录版本及命令。
- [ ] 应用、重复应用、CLI 补丁选择、回退及移除通过。
- [ ] HTTP、宿主命令、模型工具读取一致的补丁状态。
- [ ] 真实浏览器复验中英文、分区、折叠、确认、规则和提示词操作。
- [ ] 截图与候选版本一致，无 token、个人路径和私人规则。
- [ ] 沙箱场景的通过、未验和无触发源分别列明。

## 发布材料

- [ ] 变更记录、包版本和标签一致，宿主兼容声明无冲突。
- [ ] 发布说明包含安装命令、宿主版本、主要行为、回退方法和已知限制。
- [ ] 明确本地、CI、产物、安装和现场验收各自的结果，不互相替代。
- [ ] 获得本次提交、推送及正式发布的授权；这些操作不由测试通过自动授权。

项目目前采用本地目录安装。npm 包发布和自动部署不在这份清单的默认操作中。
